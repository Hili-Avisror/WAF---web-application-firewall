Chapter 1: Getting Started
--------------------------
Python is a popular programming language known for its
simple, readable syntax. To run a Python program, save
your code in a .py file and type:

    python my_program.py

Chapter 2: Variables and Data Types
------------------------------------
Variables store data. You don't need to declare a type:

    name = "Alice"      # string
    age = 25            # integer
    height = 5.6        # float
    is_student = True   # boolean

Chapter 3: Loops and Conditions
--------------------------------
Use if/else for decisions, for/while for repetition:

    for i in range(5):
        if i % 2 == 0:
            print(i, "is even")
        else:
            print(i, "is odd")

Chapter 4: Functions
---------------------
Functions group reusable code:

    def greet(name):
        return "Hello, " + name + "!"

    print(greet("Bob"))   # Hello, Bob!

Chapter 5: Lists and Dictionaries
-----------------------------------
Lists store ordered items; dictionaries store key-value pairs:

    fruits = ["apple", "banana", "cherry"]
    student = {"name": "Alice", "grade": 90}
