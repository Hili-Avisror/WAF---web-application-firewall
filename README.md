# WAF – Web Application Firewall
 איך המערכת עובדת:

1. הלקוח שולח בקשת HTTP.
2. ה־WAF מקבל את הבקשה לפני השרת.
3. המערכת בודקת האם קיימים דפוסים חשודים או מתקפות.
4. אם מזוהה מתקפה:

   * הבקשה נחסמת
   * האירוע נרשם בלוגים
   * נשלחת הודעת שגיאה ללקוח
5. אם הבקשה תקינה – היא מועברת לשרת האמיתי.


יכולות עיקריות

* זיהוי וחסימת SQL Injection
* זיהוי וחסימת XSS (Cross Site Scripting)
* הגנה מפני Path Traversal
* ניתוח בקשות HTTP
* עבודה כ־Reverse Proxy
* ניהול מספר לקוחות במקביל באמצעות Threads
* שמירת לוגים למסד נתונים SQLite
* הצגת מתקפות ופעילות המערכת
* החזרת הודעות שגיאה מותאמות במקרה של חסימה
* הוספת Headers מותאמים לבקשות ותגובות


מערכת ה־Dashboard מאפשרת:

* צפייה בלייב במתקפות
* מעקב אחרי בקשות שנחסמו
* צפייה בסטטיסטיקות
* ניתוח פעילות המערכת
* מעקב אחרי לוגים
